Спрайты поверапов
=================

Источник: Kenney — Space Shooter Remastered
Сайт: https://kenney.nl/assets/space-shooter-remastered
Лицензия: CC0 (public domain), указание автора не обязательно.

Файлы:
- powerup_invulnerability.png — powerupBlue_shield (синий щит)
- powerup_speed_boost.png     — powerupYellow_bolt (жёлтая молния)
- powerup_ammo.png            — зелёный бейдж powerupGreen + белые патроны (собран вручную)
- powerup_rocket.png          — красный бейдж powerupRed + белая ракета (собран вручную)

Два последних файла — композит: базовый бейдж взят из пака Kenney без изменений,
символы (патроны и ракета) нарисованы в том же стиле и вклеены поверх.

Настройки импорта: Sprite (2D and UI), Pixels Per Unit = 34,
Filter Mode = Point (no filter), Compression = None.

Соответствие префабам:
- InvulnerabilityPowerup.prefab -> powerup_invulnerability.png
- SpeedBoostPowerup.prefab       -> powerup_speed_boost.png
- AddEnergyPowerup.prefab        -> powerup_ammo.png
- AddRocketWeapon.prefab         -> powerup_rocket.png
